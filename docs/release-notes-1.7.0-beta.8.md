# nospacekey v1.7.0-beta.8

> 開発用証明書で自己署名した試験用プレリリースです。Windows SmartScreenの警告やアプリケーション制御による実行拒否が発生する場合があります。

## 変更点

- Windowsインストーラの自動ビルドと、別のクリーンなWindows環境でのインストール・入力・変換・削除の検証を整備しました。
- ビルドごとの版番号と配布物の同一性を管理し、異なるビルドや再署名で同じ版番号を再利用しないようにしました。
- 検証だけを再実行する場合は、同じインストーラを使い、前の検証結果も残します。

## インストールと検証

- `nospacekey-setup-1.7.0-beta.8-devsigned.exe` を使用してください。インストールと更新には管理者権限が必要です。
- ダウンロードしたexeのSHA-256を、添付の `SHA256SUMS.txt` と照合してください。
- 更新後は入力先のアプリを起動し直してください。同じ版の製品ファイルが残っている場合、インストーラは安全のため上書きを拒否します。

設定UI・Rust・Swift・実エンジンIPCの自動テストと、最終署名済みインストーラを使ったクリーンなWindows環境での検証が成功した配布物です。配布ファイルのハッシュ、IME登録、キー操作、日本語変換、利用アプリを閉じた後のアンインストールを確認しています。

## 既知の制約

- Windows x64向けです。32bit Windowsと32bitアプリは対象外です。
- 自己署名DLLを拒否するWindowsのポリシー下では利用できません。公開認証局の証明書による署名ではありません。
- 物理GPUでの推論、JISキーボードの実打鍵、Wordでの操作、旧版からの更新は今回の自動検証に含みません。
- Microsoft方式の候補数や順位、Tab予測はMicrosoft IME本体と一致しません。Windowsの日本語言語機能が必要です。
- 日本語・英字の混在入力は試験機能で、既定OFFです。自動採用と自動prefix確定は開放しません。

## プライバシー

入力内容、辞書、学習履歴を外部APIへ送信しません。自動更新確認は既定OFFで、有効にしても更新のインストールは自動では始まりません。テレメトリ、クラッシュレポート、使用統計の自動送信はありません。
