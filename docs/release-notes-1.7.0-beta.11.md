# nospacekey v1.7.0-beta.11

開発用証明書で自己署名するベータ版です。Windows SmartScreenの警告やアプリケーション制御による実行拒否が発生する場合があります。配布元を確認し、添付の `SHA256SUMS.txt` と照合してください。

## beta.10からの変更点

- MS-IME形式のユーザー辞書を取り込んだとき、「顔文字」「絵文字」の品詞分類が名詞などへ変わる問題を修正しました。辞書一覧・編集・ネイティブ形式のバックアップで元の分類を保持します。
- Google/Mozc形式への書き出しでは、絵文字を対応品詞の「顔文字」として出力し、専用コメントで元の分類を保存します。nospacekeyへ再取り込みすると絵文字の分類を復元します。
- エンジンへ渡す絵文字の優先度を記号扱いに揃えました。通常語の優先度は維持します。

## beta.7からの累積変更

上記の辞書修正に加え、beta.10で公開した次の変更も含みます。開発側から公開beta.7への未反映差分を製品ファイル全件で確認し、すべて取り込みました。

- 1文字のかなはライブ変換せず、ひらがなで表示・確定します。削除して1文字へ戻った場合も保持し、Spaceによる手動変換は引き続き利用できます。
- 記号一覧の読込失敗・空応答で選択内容が消える問題を修正し、再試行に対応しました。
- 設定の数値・パス入力で、保存中の追加入力、保存失敗、競合解決時に未保存の入力や保存状態が崩れる問題を修正しました。保存成功時の正規化・上限下限への補正にも追随します。
- GitHub Actionsの自動ビルドと別Windows VMでのインストール・入力・変換・削除検証を整備し、版番号と署名済み配布物の再利用を防ぎます。

## 検証と継続する制約

このタグのGitHub Actionsで、UI・Rust・Swift・実エンジンIPCと、署名済みインストーラを使う別Windows VMでの配布ハッシュ・IME登録・TSF入力/変換・削除を検証します。検証成功後に、同じ署名済みexeとチェックサムを公開します。

- 実GPU、物理JISキーボード、Word、旧版からの更新、ユーザーの実アプリでの手動受入は未検証です。
- Windows x64向けです。Microsoft候補はWindows公開日本語言語APIを用いるため、Microsoft IME本体の候補数・順位と一致しません。
- Zenzaiは対応GPU/Vulkan環境が必要です。混在入力の試験機能は既定OFFのままです。
