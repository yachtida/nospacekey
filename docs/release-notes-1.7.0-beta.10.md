# nospacekey v1.7.0-beta.10

> 開発用証明書で自己署名する試用候補です。Windows SmartScreenの警告やアプリケーション制御による実行拒否が発生する場合があります。最終公開前の候補です。

## 変更点

- WindowsのCRLF checkoutでも、タグ作成時だけビルドを許可するCIテストを実行できるようにしました。LF・CRLFの両方で同じ条件を検証します。beta.9はこのCIテストで停止したため、別の未使用バージョンで再検証します。

- 読みが1文字の間はライブ変換せず、ひらがなを表示します。ローマ字で `ma` と打った `ま` も対象です。`まで` から削除して `ま` に戻った場合や、Enter・暗黙確定でもひらがなを保持します。Spaceを使った手動変換は引き続き利用できます。
- 設定画面で記号一覧の読込が失敗・空応答になった際、選択した記号が意図せず消えることを防ぎます。再試行が可能です。
- 数値やパスの設定入力を保存結果に合わせて更新します。保存中の追加入力、保存失敗、競合時の選択でdraftが消えたり、未保存の入力が保存済みと表示されたりする問題を修正します。成功時の数値の正規化・clampにも追随します。

## 検証と試用

- 設定UIは開発側の固定依存で79テスト、公開同期候補で72テスト、型検査、Vite buildが成功しています。公開側の既存辞書テストとの差異は今回の修正対象に含めていません。単独かなのRustロジックを抽出したportable単体検証は4テスト成功です。
- 正式Windows Rust/Swift、実エンジンIPC、インストーラと別VMでのインストール・TSF・削除は、この候補タグのGitHub Actionsで検証します。上記Linux単体成功をWindows検証成功として扱いません。
- ダウンロードするsetup.exeのSHA256を、同じActionsのSHA256SUMS.txt・BUILD-INFO.json・検証レポートと照合してください。再ビルドや再署名した別のexeへ置き換えません。
- 物理JISキーボード、Word、実GPU、ユーザーの実アプリでの手動受入は未実施です。最終公開はユーザーの試用後に行います。

## 継続する制約

- Windows x64向けです。Microsoft候補はWindows公開日本語APIを用いるため、Microsoft IME本体の候補数・順位と一致しません。
- Zenzaiは対応GPU/Vulkan環境が必要です。混在入力の試験機能は既定OFFのままです。
- この候補は新しい版を使用します。既存beta.8のタグ・予約・固定ソース・配布物は変更しません。
