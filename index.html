Windows 用のかな漢字変換 IME。打鍵に追随して変換が進むライブ変換と、確定した瞬間に半角英数へ戻る一時日本語モードで、「モードを切り忘れる」という状態そのものをなくす。変換も学習もこの PC の中で完結する。

日本語 IME が、開発者につらい理由

$ ｇｉｔ　ｓｔａｔｕｓ
command not found

普段は半角英数のまま。F8 で入った日本語は、確定した瞬間に英数へ戻る。切り忘れという状態が存在しない。

error: expected `;`, found `；`

日本語モードの最中でも、記号は半角のまま入る。全角にしたければ設定で選べる。

議事録を取っていると、変換と確定の合いの手で手が止まる

ライブ変換は候補を出すだけでなく、確定まで自動で進む。

打てば、こうなる

そのまま打ち続けるライブ変換 — 打鍵に追随して変換が進み、確定まで自動。従来の Space 変換もそのまま使える
F8一時日本語モード — 確定した瞬間に半角英数へ復帰する
選択して 変換モードレス再変換 — 半角英数で打ったローマ字を、あとから日本語にする
Tab修正変換 — 「こんんいちは」を修復。誤読みごと学習し、次からは通常の変換で直る
Shift + 英字文中に英単語をそのまま混ぜる
(opt-in)Zenzai — GGUF モデルを置くと、文脈を読む変換がローカル CPU で動く。無ければ古典 LOUDS 変換

キーは 12 機能すべて設定 GUI でリバインドでき、衝突は保存時に検出される。起動時から半角英数で始める設定もある。

IME は、あなたが打つすべてを見ている

  • 入力内容・変換履歴・テレメトリ・クラッシュレポートのいずれも送信しない。クラウド変換 API は存在しない。
  • 変換も学習も、古典 LOUDS もニューラル(llama.cpp / CPU)も、この PC の中だけで動く。
  • パスワード欄では変換も学習もしない。
  • 全コードを公開している(MIT)。TSF 層は Rust、変換エンジンホストは Swift。
